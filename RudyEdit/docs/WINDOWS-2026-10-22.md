The fixture wrote explicit CRLF through Python text stdout. On Windows the text
stream translates each LF to CRLF, producing CRCRLF CRCRLF. JsonRpcProcess waits
for the required CRLF CRLF terminator, then sees EOF instead of the intended
missing-Content-Length error. The test waits for the latter and times out.
A Python TextIOWrapper with newline='\r\n' reproduces the byte transformation.

the editor protocol parser and all keyboard handling remain unchanged. The same
logging assertion remains enabled and must pass on native Windows.
